7. There's one complication with CICIDS2017
CICIDS2017's network model uses network-flow features.
The public dataset contains labeled network flows and features derived using CICFlowMeter. UNB Computer Science
Your Flask login page doesn't naturally produce the exact same 70–80 CICFlowMeter features.
So do not force the live login traffic through the full CICIDS2017 model.
That would create unnecessary work.
Instead:
Offline ML experiment
Use:
CICIDS2017 → Random Forest
Live demonstration
Use:
live login/application telemetry → simple feature extraction → multimodal detection layer
The dashboard can clearly show:
LIVE SECURITY TELEMETRY

Authentication     HIGH
Network Behaviour  HIGH
System Behaviour   MEDIUM

Combined Threat    HIGH

This is far simpler.
